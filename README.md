# nodak-solapi

봇이 솔라피로 문자·알림톡을 보내게 해주는 스킬. 뽀야의 사관학교 비밀기지 전용 배포본.

## 설치 (봇에게 시키기)

봇에게 이렇게 말하면 된다:

> nodak-solapi 스킬 설치해줘. `https://github.com/daht-mad/nodak-solapi`를 내 워크스페이스 `skills/nodak-solapi`에 clone하고, SKILL.md 읽고 솔라피 셋업 시작해줘.

비공개 레포라 **초대받은 GitHub 계정**으로 로그인돼 있어야 받아진다.

## 업데이트

> nodak-solapi 스킬 업데이트해줘 (`git pull`)

`.env`(내 키)는 깃에 안 올라가서 업데이트해도 그대로 남는다.

## 필요한 것

- [bun](https://bun.sh)
- 솔라피 계정 · 등록한 발신번호 · 충전금 — 없어도 괜찮다. 셋업하면서 봇이 하나씩 안내한다
