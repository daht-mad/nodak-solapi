# 솔라피 첫 연결 가이드 (봇이 읽고 주인에게 한 단계씩 안내하는 용)

> 봇에게: 이 문서는 **주인이 솔라피 화면에서 직접 해야 하는 일**이다. 한 번에 다 던지지 말고
> 아래 순서대로 한 단계씩 안내하고, 단계마다 "됐어?"를 확인한 뒤 다음으로 넘어간다.
> 언제든 `bun run scripts/setup.ts`를 다시 돌리면 어디까지 됐는지 알려준다.
>
> 메뉴 이름은 솔라피가 바꿀 수 있다. 주인이 "그런 메뉴가 없어"라고 하면 우기지 말고
> 화면 캡처를 받아서 같이 찾는다.

## 0단계 — 이 셋 중 뭐가 이미 있는지 먼저 묻기

1. 솔라피 계정이 있나?
2. 발신번호(문자 보낼 때 뜨는 내 번호)를 등록·인증했나?
3. 충전금이 있나? (없으면 연결은 돼도 문자가 안 나간다)

있는 건 건너뛴다.

## 1단계 — 가입 · 발신번호 · 충전 (주인)

- https://solapi.com 가입
- 콘솔에서 **발신번호 등록** — 문자는 미리 등록·인증한 번호로만 보낼 수 있다 (법으로 정해진 절차라 본인인증이 필요)
- **충전** — 소액이면 충분하다

## 2단계 — API Key 만들기 (주인)

솔라피 → API Key 목록 → **[새로운 API KEY]** → "신규 API Key 생성" 팝업.

이때 **허용 IP**를 정해야 한다. 기본은 빨간 **[모든 IP 허용]**이다. 뽀야도 이렇게 쓴다.

- 집 인터넷 IP는 공유기를 껐다 켜거나 통신사 사정으로 바뀔 수 있다. IP 하나만 열어두면 어느 날 갑자기 문자가 막힌다
- 노트북·클라우드 서버(Vercel 등)처럼 IP가 계속 바뀌는 곳에서 보내려면 어차피 이 방법뿐이다
- 대신 **키가 새면 아무나 내 충전금으로 문자를 보낼 수 있다.** 키는 `.env` 파일에만 두고 코드·깃·채팅에 절대 올리지 않는다

나머지 칸은 이렇게:
1. `만료 기간` — 운영용이면 "만료일 없음"이 편함
2. `API Key 메모` — "봇 문자발송용"처럼 알아볼 이름

> 더 조이고 싶으면: 봇이 늘 같은 컴퓨터(집 맥미니 등)에서만 보낸다면 `CIDR 설정`에 그 컴퓨터 공인 IP를 넣고 범위를 `/32`로 하면 그 IP만 쓸 수 있다.
> 공인 IP는 봇한테 "이 컴퓨터 공인 IP 알려줘"라고 하면 `setup.ts`가 찾아준다. 나중에 403(허용되지 않은 IP)이 뜨면 IP가 바뀐 것이다.

## 3단계 — 키를 .env 파일에 넣기 (주인)

키를 만들면 **API Secret이 딱 한 번만** 보인다. 그 창을 닫기 전에:

1. 봇에게 "솔라피 셋업 해줘" → 봇이 `setup.ts`를 돌려 `.env` 파일을 편집기로 열어준다
2. 아래 세 줄의 `=` 뒤에 붙여넣고 **저장**

```
SOLAPI_API_KEY=여기에 API Key
SOLAPI_API_SECRET=여기에 API Secret
SOLAPI_SENDER=01012345678
```

- 따옴표·띄어쓰기 없이 값만
- **채팅·DM·스레드에 키를 붙여넣지 않는다.** 대화 기록은 슬랙과 AI 서버에 남는다. 파일에만 넣는다
- 편집기가 안 열리면(원격 서버 등) 봇이 알려주는 경로를 직접 연다

## 4단계 — 확인 (봇)

`bun run scripts/setup.ts` → 잔액 조회로 연결을 확인한다 (문자 안 나감).
그다음 주인 번호로 시험 문자 1통 (`--dry-run` 먼저).

## 막혔을 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 허용 IP / 403 | 봇 컴퓨터 IP가 허용 목록에 없음 (회선이 바뀌었거나 다른 컴퓨터에서 키를 만듦) | `setup.ts`가 찍어준 IP를 콘솔 허용 IP에 추가하거나 [모든 IP 허용]으로 |
| 인증 실패 / signature | 키·시크릿 복사 실수 | 다시 복사. 시크릿을 잃어버렸으면 키 재발급 |
| 발신번호 오류 | 등록 안 된 번호 | 콘솔에 등록·인증한 번호로 `SOLAPI_SENDER` 수정 |
| 연결은 되는데 문자가 안 감 | 잔액 부족 | 충전 |
| 시간 관련 인증 오류 | 컴퓨터 시계가 15분 넘게 틀림 | 시스템 시간 자동 맞춤 켜기 |
